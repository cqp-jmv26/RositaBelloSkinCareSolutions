# Rosita Bello Skincare Solutions

One-page bilingual (Spanish default, English toggle) landing page.

## Publish on GitHub Pages
1. Create a repository and upload `index.html` and the `images` folder to its root.
2. In the repository, open Settings, then Pages. Under "Build and deployment", choose "Deploy from a branch", branch `main`, folder `/ (root)`, and save.
3. The site goes live at `https://<username>.github.io/<repository>/` within a few minutes.

## Things to update later
- Offer deadline (November 30, 2026): search `index.html` for "noviembre" and "November".
- WhatsApp number or greeting: search for `wa.me`. If the greeting changes, the QR codes in `images/qr-es.png` and `images/qr-en.png` must be regenerated.
- Before-and-after photos: replace the files in `images/` using the same file names.
